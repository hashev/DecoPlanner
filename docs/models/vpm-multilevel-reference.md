# Независимый VPM: многоуровневый ступенчатый спуск

Набор `vpmb-multilevel-descending-units.json` содержит30полных профилей:
OC/CCR/bailout × metric/imperial × консерватизм0–4. Четыре уровня:
30/45/54/60m либо100/150/180/200ft, длительности18/8/8/6min.
При bailout переход CCR→OC задан на конце введённых уровней, runtime40min.
Время каждого нисходящего уровня включает спуск10m/min. Финальный подъём9m/min,
с газовыми/SP переключениями на7и2шагах остановочной сетки.

Внешний источник — bwaite/vpmb commit
`bec938d84742e42dd43b574beec49ac26f6863ac`; перед захватом оригинальный vpmb.py
побайтно сравнивается с git object этого commit. Расчёт VPM остаётся внешним,
CCR использует ранее описанное расширение inspired pressure. Оно отвергает
пересечение dry ambient=SP; в данном наборе таких пересечений нет.
Независимая oxygen quadrature — mpmath70digits. Генератор не вызывает Dart
и не читает product output. Исходники внешнего алгоритма остаются в local/.

## Единицы и захват

Обе ветви используют канонические bar/metres: surface1.01325bar,
vapour.0493bar, hydrostatic.1bar/m. Футы переводятся точно через.3048;
imperial stop grid —10ft=3.048m. Внешний source исполняет MSW-уравнения с
этой физической сеткой. Это не проверка его самостоятельных FSW default presets.

Сохраняется действующая нормализация minimum-stop +.501, Boyle maximum trial
first-stop, refined roots и SI0 finalization. Для fractional grid выявлена
особенность output layer upstream: при целом minimum stop time печатная
глубина hold преобразуется в int. Физическая выдержка остаётся в предыдущей
сырой точке ascent. Генератор сохраняет `reported_end_depth_m` отдельно;
`end_depth_m` и oxygen quadrature используют физическую точку. Ни runtime,
ни длительность, ни ткани/пузырьковые параметры source не подгоняются под Dart.

Сравнение включает все8введённых физических сегментов, все сегменты финального
подъёма/остановок, газы/SP, состояния16тканей, начальные/конечные bubble vectors
и saved tissues, CNS/OTU, serialization и неизменность исходного CCR при bailout.
Используется штатный CalculationBudget100000, без ослабления ресурсного лимита.
Допуски назначены по уже принятому контракту до сравнения: time1e-7min,
tissues/gradients1e-8bar, radius1e-15m, CNS1e-10, OTU1e-9.

## Границы и отклонённые кандидаты

Это проверка многоуровневого нисходящего профиля, а не всех вариантов multilevel.
Исходный кандидат с промежуточным подъёмом/повторным спуском был отложен до
нормализации: продукт рассчитывает декомпрессию к новому уровню и выравнивает
время выдержки, а нативный profile_code1 описывает прямое движение. Результаты
этих разных запросов нельзя сравнивать как одну постановку. Внешний source также
может выдавать invalid bracket, если финальная введённая точка уже внутри deco
zone. Эти ограничения не означают, что ветви приложения можно исключить из
итогового аудита; upward/redescent теперь проверен отдельными60полными профилями, включая реальные промежуточные остановки; общий аудит11.1 остаётся открытым.

Кандидаты и диагностические запуски хранятся отдельно в игнорируемом
local/oracles/diagnostic-candidates; они не объявлены принятыми эталонами.
Существующие baseline/independent snapshots не перезаписаны.
