# Реестр решений по исправлениям

Машиночитаемый источник — [corrections.json](corrections.json). Он покрывает
подтверждённые дефекты, статические подозрения и ограничения из
[limitations.md](../calculations/limitations.md). `pending` означает отсутствие
реализации/проверки, а не согласованное исключение из объёма работ. Исходные
ошибки и результаты остаются в legacy_baseline и optional local/reference;
исправленные ожидания должны иметь отдельное независимое происхождение.

Для каждой записи указаны диагноз, целевое правило, область задач, источник и
обязательные проверки. Ссылки на ожидающие проверки источники явно помечены:
это ещё не принятая численная политика. Реализация обязана обновлять статусы
только после проверок. Реестр не заменяет численную матрицу готовности.

## VPM: решения, которые нельзя принимать по сходству кода

**ANY сохранён как правило модели**, а не признан дефектом. В независимой
[реализации VPM-B Bryan Waite](https://github.com/bwaite/vpmb/blob/bec938d84742e42dd43b574beec49ac26f6863ac/vpmb.py#L1887)
комментарий и цикл явно устанавливают сходимость при изменении фазового времени
не более минуты хотя бы в одном из 16 компартментов. Ограничения числа итераций
нужны отдельно и не меняют математический критерий на ALL.

**Projected ascent остаётся подозрением.** Независимый
[метод](https://github.com/bwaite/vpmb/blob/bec938d84742e42dd43b574beec49ac26f6863ac/vpmb.py#L1049)
изменяет `Deco_Stop_Depth`, а вызывающая сторона использует побочный эффект.
Legacy отбрасывает возвращённого кандидата. Перед исправлением нужен пример,
где кандидат углубляет первую остановку, и сопоставление промежуточного состояния.
Один факт `pop2` ещё не доказывает ошибку расписания.

## Граница независимой проверки

Существование независимой реализации не подтверждает совместимость соглашений.
У B/C различаются первая ткань, начальная доля азота и стратегия остановок.
Полученный VPM oracle реализует OC: прочитанные поля setpoint не участвуют в
расчёте. Upstream-native output нельзя объявлять CCR/bailout эталоном. Полные CCR/bailout сравнения используют явно описанное inspired-pressure расширение внешнего источника и independent oxygen quadrature. Подробнее:
[independent-references.md](independent-references.md).

## Уточнение, обнаруженное при реализации: газ мультиуровневого подъёма

В исходных OC B/C36→21m сегмент подписан как50%/0He, однако последовательное
независимое применение DecoTengu к таким сегментам **не** воспроизводит исходные
конечные ткани. Если только на этом подъёме использовать предыдущий21/35,
совпадают все16 N2/He. Для первой ткани: ошибочный replay по подписи даёт
N2=1.3362572033305353bar, He=0.005577191131436742bar; правильный газ даёт
N2=1.329236662626602bar, He=0.009455631214686969bar, как оригинальные ткани.

Целевое поведение: ткани и подпись сегмента используют предыдущий газ; переход
на газ нового уровня происходит при достижении его глубины. Время и исходные
финальные ткани сохраняются. Два отдельных regression JSON содержат исправленную
подпись и независимые tissue snapshots. Первоначальные baseline не изменены.

```sh
local/oracles/python-env/bin/python tool/capture_schedule_replay.py
```

Этот replay проверяет математику тканей по сохранённому расписанию; он **не**
считается независимо разработанным поиском самих остановок. Provenance явно
разделяет эти две степени независимости.

## CNS movement: равенство нижней границе

S.D при движении обрезает нижний PO2 до0.5. Последующая строгая проверка
`minimum < bandLow` пропускает равенство и fallback относит весь участок к первой
полосе, повторяя часть диапазона вместе с другими полосами. Изолированное
исполнение оригинала для воздуха0→30m/3min дало CNS0.004973526151167392,
независимая квадратура опубликованной таблицы —0.0026519428999620699709.
OTU совпадает. Новый интегратор использует явное пересечение интервалов.

Публичный regression хранит оба результата с хешами. Поэтому на полном
air30m/20min конечный CNS меняется с legacy0.050839995582775674 на корректный
интеграл0.04593887538578666; это доказанное исправление, не увеличение допуска.
Проверены также независимые кислородные интегралы всех14выбранныхOC расписаний.

## VPM: переставленные веса газовых градиентов

В H.B() первичные N2/He gradients вычислены из соответствующих радиусов правильно:
`m=N2`, `S=He`, затем `f=m`, `M=S`. Однако H.E()/H.C() взвешивают `f/a` давлением
`q=He`, а `M/F` — `T=N2`. Порядок присваивания и весов подтверждён байткодом,
не только CFR. Поэтому правильные исходные параметры сами по себе не дают
правильное расписание. В новом ядре каждый газ получает собственный градиент.

Независимый oracle с намеренно переставленными current gradients воспроизвёл
**все** глубины/длительности c0–c4 оригинала и конечные16N2/He. Та же независимая
реализация с правильными весами подтверждает новые расписания. Диагностический
вариант существует только в fixture generator, в продукте его нет.
См. `independent/vpmb-normalized-schedules.json`:17corrected +5diagnostic cases.

No-deco ветвь оригинала дополнительно рассчитывает ткани подъёма, не сохраняя
сам сегмент. Для10m/10min финальная N2 ткани0=1.3120821501154936bar совпадает
с surfaced независимым расчётом, хотя legacy содержит только спуск/выдержку.
Новый результат содержит физический подъём, согласованные runtime и кислород.

## Актуализация реестра

Убраны старые pending-отметки уже проверенных contracts (budgets, ANY, projected
safeguard, нулевые значения, immutable state и authoritative profile). Это не
переименование подозрений в подтверждённые дефекты: ANY остаётся намеренным
правилом, normal legacy schedule effect projected guard остаётся недоказанным,
резервы — границей scope, неофициальный архив — ограничением provenance.
Read-only completeness/evidence check: `python3 tool/audit_corrections.py`.
