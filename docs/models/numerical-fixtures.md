# Реестр численных эталонов

[Машиночитаемый снимок](numerical-fixtures.json) охватывает все 140 JSON файлов
расчётных эталонов. Проверка без приватных зависимостей:

```sh
python3 tool/audit_numerical_fixtures.py
python3 tool/audit_corrections.py
```

Аудит проверяет полноту инвентаря, уникальность путей, SHA-256 каждого файла,
схему верхнего уровня, конечность чисел, сохранённое происхождение и допуски.
Для сравнений закреплены SHA файлов тестов с фактическими полевыми assertions:
численные величины имеют свои допуски, дискретные поля сравниваются точно.
В частности, Subsurface constant-SP controls используют аналитическую границу
ошибки константы ln2; общий произвольный допуск для всех полей не применяется.
Изменение тестового контракта требует отдельного пересмотра снимка.

| Роль | Файлов | Что подтверждает |
|---|---:|---|
| Исходные наблюдения | 90 | 89 legacy baseline и 1 файл density presentation; сохраняют и ошибки оригинала |
| Исходные параметры | 2 | Наблюдённые таблицы; не независимая верификация |
| Native diagnostic | 7 | Несогласованные defaults внешнего движка; не критерий приёмки полного плана |
| Независимые компоненты | 13 | Кинетика, физика VPM, кислород, EOS, mixing, расход и другие явно ограниченные контракты |
| Кинетика на исходном расписании | 14 | Ткани и исправленный gas label; не независимый поиск остановок |
| Кислород на исходном расписании | 1 | Интегралы на сохранённой траектории; не stop search |
| Нормализованные полные планы | 10 | Файлы с множеством профилей и последовательностей, включая высоту/SI и обе системы единиц |
| Исправленные regressions | 3 | CNS boundary и 2 multilevel gas-label; последние побайтно связаны с независимым replay |

Три группы legacy/independent/regression сохраняют разные назначения.
Число файлов не равно числу профилей или тестов. Генераторы не читают Dart
actual; исправленные ожидания не получены обратной записью результата приложения.
Для двух gas-label regressions дополнительно проверяются SHA исходного baseline,
SHA независимого replay и точное равенство expected независимому источнику.
Изменение/добавление любого JSON требует явного пересмотра реестра;
публичный аудит ничего не перезаписывает и не имеет update-режима.

Соглашения источников и ограничения приведены в
[normalization](reference-normalization.md), покрытие исправлений — в
[corrections](corrections.md), новая imperial матрица — в
[B/C CCR/bailout](buhlmann-imperial-reference.md).
Проверка хешей подтверждает сохранность уже проверенных данных; самостоятельное
повторное выполнение внешних источников требует приватного oracle environment,
версии и команды которого сохранены в provenance. Наличие хеша само по себе
не объявляется повторным запуском источника.
