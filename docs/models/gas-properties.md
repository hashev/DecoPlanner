# Свойства газа: контракт ядра

`GasProperties` принимает доли0..1, глубинуm и явный PressureContext.
PO2 в API — **bar**; при вводе ATA вызывается `Units.ataToBar`.
MOD/min depth решаются из физического парциального давления. Для O2=0
возвращается `null` (неприменимо), а не Infinity. MOD ниже поверхности
также неприменим; minimum depth ограничивается поверхностью.

END использует выбранный коэффициент наркотичности O2 от0 до2, в том числе
0/0.3/1/2 из исходного UI. Это параметр модели, не физиологическая рекомендация.
Вычисления double, без исходных промежуточных float32 округлений.

Плотность сохраняет исследованную линейную модель:1.43/0.18/1.25g/L для
O2/He/N2 при1ATA; воздух21/0 —1.2878g/L. Это reference-condition model,
не EOS заправки. Температура не подразумевается как вход этой функции.

Подбор смеси сначала решает PO2 и END без округления долей. При неограничивающем
END используется He0; невозможный target даёт типизированный отказ.
Округление десятых процента выполняется только представлением. Поэтому
в отдельных случаях последние десятые He могут отличаться от legacy, который
промежуточно округлял O2 перед вычислением He.

Проверки: аналитические MOD/min depth, физический баланс PO2/END, чистые
компоненты, воздух, кислород без инертных, недостижимые/нечисловые входы,
три неизменённых legacy-density observation с хешами и пример45m/1.3ATA/END30
с отображением23.9/27.2. Ниже публикуемой области density это не расширенная
температурная модель.
