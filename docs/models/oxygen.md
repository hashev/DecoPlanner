# Кислородная политика baker-seven-bands-si90-v1

Источник: Erik C. Baker, P.E.,
[Oxygen Toxicity Calculations](https://cdn.shopify.com/s/files/1/0838/3732/1530/files/Oxygen_Toxicity_Calculations.pdf?v=1710181583),
12страниц, формулы1–6, коэффициенты настр.8. PDF сохранён только локально;
SHA-256 записан в independent/oxygen-baker-mpmath.json. Таблица визуально сверена.

PO2 модели вATA, времяmin, CNS — доля; API принимаетbar с явным переводом.
При PO2≤0.5 приращения нулевые; выше1.6ATA — доменная ошибка. Семь полос:

| PO2ATA | slope | intercept |
|---|---:|---:|
| (0.5,0.6] | -1800 |1800 |
| (0.6,0.7] | -1500 |1620 |
| (0.7,0.8] | -1200 |1410 |
| (0.8,0.9] | -900 |1170 |
| (0.9,1.1] | -600 |900 |
| (1.1,1.5] | -300 |570 |
| (1.5,1.6] | -750 |1245 |

CNS rate=1/(slope·PO2+intercept). Movement пересекает все применимые полосы;
OTU rate=[2(PO2−0.5)]^(5/6). Оба интегрируются по фактическому линейному PO2,
с отсечением времени ниже порога. Никаких fixed2/duration/.2 при highPO2.

На surface interval CNS умножается на2^(−minutes/90); SI0 — identity.
OTU сохраняется как накопленная экспозиционная доза, без неподтверждённого
восстановления и скачка reset в24h. Это не rolling24h/daily-limit модель.
Восстановление CNS — описанная автором планировочная конвенция, не измеренная
физиологическая кривая для всех ситуаций.

Численные эталоны получены **независимой квадратурой mpmath65digits** по
опубликованным полосам, а не аналитическим product интегратором:43boundary/band/
movement cases, по каждому направлению,5SI значений и3примерных сегмента.
Допуски до сравнения: CNS1e-12 absolute, OTU1e-10 absolute. Высокие значения
за пределом проверяются как ошибки, не как успешный численный эталон.

В печатном worked CNS example автора округлённый total0.2746 не совпадает с
интегралом его опубликованной таблицы: для точных120ft/EAN32/3+22+30min
независимая квадратура даёт0.27757687703086019. За правило модели приняты
формулы/коэффициенты, а не эта итоговая иллюстрация. Нельзя подгонять expected
или допуск к напечатанному total; исходный пример остаётся отдельно описанным.

## Решение владельца: неизвестный CNS не блокирует декомпрессию

Остановка O2 на20ft даёт1.606ATA. Владелец выбрал: рассчитывать ткани/расписание
и OTU, а CNS вне1.6ATA показывать как недоступный с причиной.
`OxygenState` содержит либо конечную численную CNS-долю, либо `null` и
`CalculationFailure(outsideModelDomain)`. После неизвестного CNS нельзя
восстановить известный ноль расчётной паузой; неизвестность переносится дальше,
в том числе через SI1440 и JSON. OTU остаётся числом по своей отдельной формуле.

Прямой CNS evaluator по-прежнему возвращает доменную ошибку. Production segment
adapter обрабатывает только эту ошибку как статус метрики; неверный ввод,
nonfinite и другие failures не скрываются. Экстраполяция CNS выше1.6 не принята.
Дополнительные OTU-эталоны получены отдельно в
independent/oxygen-outside-cns-domain-mpmath.json; базовые ожидания не заменены.
