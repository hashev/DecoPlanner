# Дизайн-система

Инструментальная, спокойная, с высокой читаемостью чисел. Результат поиска ui-ux-pro-max из design.md использован выборочно: Minimalism & Swiss Style, ясная типографика и формы. Маркетинговые hero/CTA-шаблоны и scroll reveal не применяются. Источник токенов — [tokens.json](tokens.json), измерения — [contrast.json](reports/contrast.json).

## Цвет и шрифт

| Роль | Light | Dark |
|---|---|---|
| Фон / поверхность | #F8FAFC / #FFFFFF | #0F172A / #1E293B |
| Основной / дополнительный текст | #0F172A / #475569 | #F8FAFC / #CBD5E1 |
| Основное действие / текст на нём | #1E40AF / #FFFFFF | #93C5FD / #0F172A |
| Warning / Error / Success | #92400E / #B91C1C / #166534 | #FCD34D / #FCA5A5 / #86EFAC |
| Граница контрола | #64748B | #94A3B8 |
| Фокус | #1E40AF | #93C5FD |

Разрешённые текстовые роли используются только на surface/background; onPrimary — только на primary. Нет прозрачных слоёв или смешивания role цветов между темами. Каждая статусная роль сопровождается словом. Линия профиля primary, сравнение — secondary со штрихом, обозначения газов — текст O2/He. Значимые границы и фокус имеют 3:1, текстовые пары — 4.5:1; все 34 пары проверяются `python3 docs/ui/tools/check_contrast.py`.

Для будущей реализации: Fira Sans (кириллица), избранные числа Fira Code; локальная поставка шрифтов с лицензией. В текущем окружении Fira Sans/обычная Fira Code не найдены через fontconfig; SVG используют явный локальный fallback Verdana/sans-serif, что указано в манифесте. Это не проверка метрик финального Flutter-шрифта. Основной текст 16/24, вспомогательный 14/20, заголовки 20/28 и 24/32, числовые сводки 28/36. На увеличенном тексте размеры не ограничиваются сверху; карточки растут по содержимому.

Отступы 4/8/12/16/24/32, радиусы 8/12, текст 400/600. У форм maxWidth640, у длинного текста 720. Тени не нужны для разделения соседних панелей: используется граница/отступ. Поля минимум 56 высотой, кнопки минимум 48, строки touch-списка минимум 56; маленькая иконка 24 имеет hit area48. Не уменьшать цель при desktop-плотности. В макетах основные действия текстовые; в реализации единая семья Material Symbols outlined, без emoji/копирования PNG оригинала.

## Компоненты и адаптация

| Компонент | <600 | 600–999 | ≥1000 |
|---|---|---|---|
| Навигация | Нижние 3 destinations | Rail, одна основная панель | Rail, редактор + результат |
| Редактор уровня/газа | Отдельный экран с Сохранить/Отменить | Основная панель, форма≤640 | Панель 340–420; вложенный редактор |
| Строка остановки | Сводка + раскрытие полей | Список либо таблица по месту | Таблица + панель деталей |
| Статус/ошибка | Переносимый текст, без обрезки | Inline над содержимым | Над результатом и рядом с полем |
| Диалог | Fullscreen при нехватке высоты | По содержимому, maxWidth560 | Диалог 560, фокус внутри |
| График | Точка по tap, таблица альтернативой | Более широкая область | Pointer + keyboard, легенда |
| Сводка | Вертикальные метрики | Перенос строк | Горизонтальный ряд при достаточной ширине |

Размер окна измеряется LayoutBuilder; ориентация/название устройства не выбирают layout. При шрифте 200% перейти к последовательным панелям даже при 1000; не сохранять тесную двухпанельную сетку. Широкая компоновка требует места для rail88 + gutters48 + editor340 + gap16 + result480 =972, поэтому порог 1000 оставляет запас. При 600 доступно content480, форма не растягивается. Границы 599/600 и 999/1000 проверяются отдельными макетами. Результат, выбранный dive и черновик живут выше ветки layout.

## Состояния контролов

| Состояние | Представление / поведение |
|---|---|
| Default | Surface, подписанное поле, border1, текстовый hint |
| Hover | Border primary, без изменения размеров; необязателен для доступа |
| Pressed | Рамка 2 + немедленная обратная связь; без сдвига соседей |
| Focus | Внешняя рамка 2, отступ 2, label остаётся видимым |
| Invalid | Error border, текст причины под полем и ссылка в summary |
| Disabled / unavailable | Подпись «Недоступно» и причина, disabled semantics; не только opacity |
| Calculating | Статус «Расчёт…», повторный action disabled, ввод сохраняется |
| Stale | «Входы изменены — пересчитайте», прежний snapshot с подписью |

Не анимировать цифры расчёта. Feedback80–150ms, переход около 200ms; reduced motion убирает перемещения. Реакция на ввод не ждёт анимации. SVG статичны; это описание будущего поведения.

## Доступность и ввод

Safe areas: нижняя навигация и action bar резервируют место под системные области. Мобильная клавиатура изменяет доступную высоту; поле и Сохранить прокручиваются в видимую область, фиксированный CTA уступает место при нехватке высоты. Один основной scroll в узкой панели. Кнопка Back и системный Back одинаковы по смыслу. Область выбора точек графика не перехватывает вертикальную прокрутку всей страницы.

Tab/Shift+Tab следуют визуальному порядку. Enter подтверждает активную форму; Command+Enter/Ctrl+Enter запускает расчёт плана. Escape отменяет диалог, возвращая focus инициатору. Удаление строки — явная кнопка; Delete в поле редактирует текст. Перестановка имеет Вверх/Вниз, не только drag. Обязательных swipe/hover нет.

Screen reader получает имена с величиной и единицей («Глубина, метры»), selected/expanded/disabled и состояние расчёта. Декоративная иконка при тексте исключается из semantics; отдельная кнопка имеет имя. Ошибка объявляется при submit, не на каждую цифру. При множестве ошибок focus перемещается в summary с переходами к полям; inline errors сохраняются. График имеет таблицу и текстовую сводку. Фокус не должен уходить под закреплённые панели.

Статический walkthrough: все формы редактируются без жестов; по keyboard-порядку доступны сохранить/отмена; пустой ввод не исчезает при ошибке; контраст обеих тем измерен. Макеты 200% и размерная матрица проверяют геометрию. Реальные VoiceOver/TalkBack/Narrator, keyboard insets и reduced motion ещё требуют Flutter runtime-проверки из handoff.
