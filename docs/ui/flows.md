# Навигация и сценарии

Глобально: **План · Инструменты · Настройки**. Результат всегда относится к выбранному погружению. Переход между разделами сохраняет черновики в текущей сессии. Хранение между запусками приложения потребует отдельного требования; здесь оно не обещается.

## P01

Открыть план → выбрать погружение → P02. Добавить следующее → задать поверхностный интервал → P02. Список показывает порядок, режим, статус и зависимость от предыдущего. Расчёт dive N сначала требует актуального состояния всех предыдущих; действие «Пересчитать последовательность» обрабатывает зависимости по порядку. Bailout — ветвь сценария, а не следующее реальное погружение.

Проверка OC: P01 → OC → P02 → P03 → расчёт → P04 → P05/P06/P08 → назад в P04. Проверка repetitive: добавить dive 2 с SI 90 мин → пересчитать → изменить dive 1 → оба результата stale → повторный расчёт по порядку. Пройдено как проверка спецификации, не runtime-тест.

## P02

Выбор уровня → отдельная форма на телефоне / панель в desktop → изменить → Сохранить либо Отменить. Добавление и перестановка доступны кнопками; drag — необязательное дополнение. CCR показывает setpoint и дилюент. Переход в P03 не запускает расчёт. «Рассчитать» проверяет весь ввод, фиксирует revision и при успехе открывает P04; при ошибке оставляет форму. «Добавить» и «Удалить» не привязаны только к клавише Delete.

## P03

Выбрать набор → загрузить копию газов в текущий план → редактировать состав, глубину переключения, минимум стопа, lost gas при применимости. «Сохранить как набор» меняет справочник S02, «Применить» меняет текущий план. Отмена редактора газа возвращает предыдущий состав. CCR переключения дилюента/PO2 не подменяются OC-списком декогазов.

## P04

Показать сводку → остановки → раскрыть строку → P05/P06/P08. Все поля таблицы доступны в раскрытии на телефоне; desktop сохраняет заголовки при прокрутке. Нет hover-only чисел. Пустой результат показывает предложение рассчитать. Неактуальный результат сохраняется для сравнения с видимой подписью и не считается текущим планом.

## P05

P04 → профиль → выбрать серию/точку касанием, кликом или клавиатурным списком точек. Глубина растёт вниз, время вправо. «Только подъём» меняет вид, не входы. «Сохранить сравнение» сохраняет snapshot с входами, моделью, revision, датой/именем. «Ткани» → все/1–16 → N2/He/M-values → таблица точек. Ratios — подписанная округлённая сводка. Очистить сравнения → подтверждение → P05, черновик не изменён.

## P06

P04 → расход на одного дайвера без резервов → выбрать баллон каждого газа → требуемое давление. Отсутствует рассчитанный резерв, давление расхода не называется рекомендуемым начальным давлением. В CCR кислород и дилюент различаются. Отмена выбора сохраняет предыдущий баллон.

## P07

P01 → CCR → P02/P03 → актуальный P04 → «Планировать bailout» → P07. Показать источник и точку перехода → редактировать последовательность CCR/OC → газы → расчёт bailout → собственные P04/P05/P06. Back возвращает в CCR. Исходный CCR не изменяется. Изменение источника делает bailout stale; повторное связывание показывает, какие пользовательские изменения сценария заменятся.

## P08

P04 → диапазоны глубины/времени → выбрать вариант базовый/без декогаза/без CCR-переключений → построить → матрица либо список. Каждая ячейка имеет статус/ошибку. Открыть ячейку → её полный результат; назад — диапазон. «Печатный вид» → preview с входами, моделью, единицами, актуальностью. При stale предложить пересчитать, не экспортировать как актуальный. Системная отмена/недоступная печать сохраняет preview и план.

## T01

Каталог инструментов → MOD/END → состав, пределы PO2, глубина и наркотичность O2 → расчёт → min/max operating depth и END. Изменение любого входа делает ответ stale. Возврат в каталог сохраняет ввод.

## T02

Каталог → плотность → состав/глубина → расчёт → г/л и эквивалентная глубина воздуха с условиями. Табличного численного ответа до расчёта нет.

## T03

Каталог → подбор смеси → глубина/PO2/END/наркотичность → рассчитать → O2/He/N2 → явное «Добавить газ в план» → выбрать назначение и подтвердить. Никакой автоматической замены существующего газа.

## T04

Каталог → смешивание → текущая и целевая смесь/давление → метод и применимые опции → расчёт. Успех: пошаговое добавление/доведение; drain: отдельный первый шаг стравливания; impossible: причина без действующей инструкции. Успешный актуальный рецепт → T08. Изменение рецепта инвалидирует T08. Непрерывный вариант 1/2 и применимые пределы потоков видны только для соответствующего метода; real/ideal не объявляются доступными, если backend этого сочетания не поддерживает.

## T05

Каталог → дозаправка → текущий газ/давление, добавляемый газ, конечное давление → расчёт → итоговый состав. Конечное давление не выше исходного — ошибка, а не незаметное отрицательное добавление.

## T06

Каталог → уравнивание → объём/давление двух баллонов → расчёт → итоговое давление. Equal-pressure — корректный граничный случай; предупреждение о порядке low/high не требует потери ввода.

## T07

Каталог → конверсия → выбрать направление → заполнить исходные объём/давление → преобразовать → целевые значения. Оба результата подписаны, исходные не переписываются. Подпись о приблизительности видима.

## T08

T04 → объёмы/стоимость → выбрать баллон, цены O2/He и фиксированную доплату → пересчитать стоимость → составляющие/итог. Валюта — подпись пользователя/условная единица, не обменный курс. Возврат в T04 сохраняет цены и баллон; изменение рецепта делает стоимость stale.

## S01

Параметры текущего плана → выбрать модель → применимые поля → Применить к плану / Отменить. Отдельное «Сохранить по умолчанию» влияет только на новые планы. Инвалидирование затрагивает расчётные параметры, а не тему. Высота выключена — значения хранятся, но не участвуют; acclimatized выключает неиспользуемые поля поездки с объяснением.

## S02

Настройки → справочники / вид / справка. Наборы и баллоны редактируются копией с сохранением/отменой. Удаление используемого элемента показывает ссылки и требует выбрать замену либо отменить. Смена единиц при незавершённом невалидном вводе сначала предлагает исправить или отменить его. Офлайн-справка открывает определения; внешняя ссылка только по явному действию.

## Exclusions

Регистрация, лицензирование, обновления оригинала, Silver theme и расчёт резервов исключены. Нельзя переходить к ним через неработающие кнопки. Исходная заставка и её условия не копируются.

## Машина состояний

| Было / событие | Станет / действие |
|---|---|
| empty + добавить уровень | draft, focus на первом поле |
| draft/stale/error + submit invalid | invalid, значения сохранены, summary + inline errors |
| valid + submit | calculating(revision R), повторный submit недоступен |
| calculating R + успешный ответ R | ready R, перейти в P04, announce завершение |
| calculating R + изменение ввода | draft/stale R+1, старый ответ R игнорировать |
| calculating + ошибка/таймаут | error, причина + Повторить/Изменить; черновик сохранён |
| любой + capability отсутствует | unavailable, причина; демонстрация не подменяет расчёт |
| ready + расчётный ввод | stale, сохранить прошлый snapshot с подписью |
| ready + тема/масштаб/раскрытие | ready, revision не меняется |
| изменение dive N | invalidate N и все зависимые dive/bailout |

Разделять revision физического запроса и настройки отображения. Смена единиц только преобразует вид, если физические значения сохранены; реальные изменения округлённых входов создают новый revision. Вспомогательные инструменты имеют собственный revision, T08 дополнительно хранит recipeRevision.

## Подтверждения и восстановление

| Действие | Перед подтверждением | Отмена / подтверждение |
|---|---|---|
| Сбросить план | Число погружений, потеря уровней; отдельная опция сравнений | Сохранить всё / очистить только названные данные |
| Удалить dive | Перечень зависимых результатов/сценариев | Сохранить всё / удалить dive, инвалидировать связи |
| Сменить OC/CCR | Какие поля несовместимы | Оставить режим / преобразовать черновик с явным итогом |
| Закрыть изменённый редактор | Сохранить / Отбросить / Продолжить | Возврат в форму или исходный экран |
| Очистить сравнения | Только snapshots, не уровни | Сохранить / очистить snapshots |
| Ошибка расчёта | Причина, Повторить, Изменить вход | Повтор использует тот же черновик и новый request ID |

Спецификационные walkthrough выполнены для: изменения dive 1 из трёх (все stale); смены газа во время расчёта (старый ответ игнорируется); таймаута (ввод сохранён); недоступной VPM-ветви (нет fake-ответа); Escape/Back отмены (восстановлен исходный редактор). Это логическая проверка сценариев, без исполнения приложения.
