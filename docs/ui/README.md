# UX-проект DecoPlanner для Flutter

Дизайн-пакет для iOS/Android и desktop macOS/Windows. Здесь исследование интерфейса оригинала, целевые сценарии, компоненты, аннотированные SVG и PNG-превью. Это статический проект интерфейса: Flutter-приложение и новое расчётное ядро ещё не реализованы.

Начать просмотр с [индекса макетов](mockups/README.md). Выбрать экран и тему; номера 2/3/... показывают продолжение прокрутки того же экрана. Для редактирования рядом с PNG находится одноимённый SVG. Варианты OC/CCR внутри дизайн-страниц показывают состав альтернативных форм, а не одновременно обязательные поля. Рамки, группы действий и подписи — спецификационные обозначения будущих Flutter-контролов.

## Основная структура

Три глобальных раздела: План / Инструменты / Настройки. В плане: последовательность погружений, уровни, газы и результаты выбранного dive. Bailout — связанный сценарий CCR. На телефоне отдельные представления; в широком окне редактор и результат соседствуют. Единая модель состояния сохраняет ввод при смене layout.

Мобильные и настольные основные макеты представлены в обеих темах. Дополнительно есть landscape, промежуточная ширина, граничные размеры 599/600 и 999/1000, текст 200%, ошибки, stale, calculating, unavailable, reset, смешивание с drain/impossible и печатный preview. Подробности и происхождение чисел — [манифест](mockups/manifest.json).

## Как воспроизвести

Из корня репозитория, Python3 без сторонних Python-зависимостей:

```sh
python3 docs/ui/tools/build_reference.py
python3 docs/ui/tools/check_contrast.py
python3 docs/ui/tools/render_mockups.py --matrix
python3 docs/ui/tools/build_gallery.py
python3 docs/ui/tools/audit_design.py
```

Для PNG нужен установленный `rsvg-convert`, для контактных листов — `magick` (оба доступны в среде исследования). Генераторы пишут только производные материалы `docs/ui/`. Редактируемые данные экранов — [screen-model.json](screen-model.json); дизайн-токены — [tokens.json](tokens.json). `check_contrast.py` читает tokens.json и проверяет разрешённые пары, не меняя цвета. SVG использует доступный Verdana fallback; финальные шрифты Flutter требуют отдельной runtime-проверки.

После изменения макетов выполнить их просмотр: успешный структурный аудит не заменяет визуальную проверку. Система не запускает оригинал, не выполняет численных расчётов и не подключается к сетевым сервисам.

## Локальные исследовательские проверки

Оригинал и анализ перемещены в игнорируемый `local/reference/`. Пути `analysis/...` в исторических данных относительны этой области. См. [инструкцию](../development/reference.md). `audit_design.py` по умолчанию проверяет только публичные материалы; `--with-reference` явно включает оригинальные источники, численные наблюдения и хеши. `build_reference.py` и `export_legacy_baseline.py` требуют локального архива.
