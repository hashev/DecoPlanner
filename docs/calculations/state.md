# Настройки, данные и изменяемое состояние

Статус: подтверждено чтением/записью в байткоде. Полный машинный индекс каждого
поля, включая вызывающий метод и строку `javap`, находится в
field-accesses.json (локально: `../../local/reference/analysis/maps/field-accesses.json`).
Неиспользуемое ниже означает отсутствие getfield/getstatic в исследуемых классах,
а не гарантию о внешнем доступе через reflection.

## J — один план погружения

| Поля | Назначение |
|---|---|
| `M`, `F`, `X` | номер погружения, bottom duration для range-table, флаг range-table |
| `i`, `h` | bailout включён и индекс исходного diluent для перехода |
| `D`, `c`, `f` | surface pressure, water vapor pressure, исходное N2 (f после конструктора не читается) |
| `m` | surface interval, минуты |
| `Q`, `J`, `G`, `R` | начальные N2[16], He[16], CNS, OTU |
| `V`, `e`, `Y`, `A` | конечные N2[16], He[16], CNS, OTU |
| `n`, `H` | внутренние сегменты и газы |
| `P`, `S`, `k`, `C`, `_` | исходные OC-уровни, CCR-уровни, OC gases UI, CCR switches UI, баллоны плана |
| `I`, `d` | таблицы результатов OC и CCR |
| `U`, `a`, `T` | текущий индекс газа, глубина, runtime |
| `j`, `N` | текущая скорость; текущий шаг (N записывается, но не читается) |
| `g` | текущий CCR setpoint (использует D) |
| `Z` | depth start of off-gassing |
| `b` | наклон линейной интерполяции GF |
| `E`, `l` | учитываемая длительность deco / суммарное время подъёма |
| `B`, `L` | максимальное отношение tissue/M-value и GF (доли) |
| `W` | флаг отмены после first-stop conflict |

`J.H()` инициализирует N2 из `O.J()`, He=0, CNS=OTU=0.
`J.E()` копирует M.E/G/A/F. `J.A(...)` добавляет газ с дедупликацией по составу
(и отдельной перегрузкой для setpoint); не заменять это простой добавкой в список.

## d — сегмент и h — газ

См. [contract.md](contract.md). Поля d.Q/H/L/J/M не имеют чтений/записей в
поставленных классах; их не нужно включать в минимальное состояние нового ядра.
`d.T/K` — реально используемые снимки тканей. `h.N/J/A` = O2/He/N2, `G`=роль
(1 bottom, 2 deco), `B`=switch depth, `P`=minimum stop override, `L`=setpoint,
`H`=gas volume, `Q`=округлённое время на газе, `C`=число декостопов.
Резервы эти поля не содержат; см. справочник расхода; JavaFX properties и `Tank` нужны
для отображения, а не тканевого состояния.

## G / V — строки таблиц

Доказательство — setters из `S.A(DDD)`, `A.B(DDD)` и cell value factories W/R.
Хранить значения и их форматирование отдельно.

| Строка | private fields в порядке смысла |
|---|---|
| G (OC) | G depth; D duration; J O2%; E He%; B start; H end; K PO2; L gas volume; C supersaturation%; A GF%; N CNS fraction; F OTU; M special-row flag; I string property не используется |
| V (CCR) | I depth; G duration; F diluent O2%; Q diluent He%; D start; J end; M PO2; K effective O2%; N effective He%; E supersaturation%; C GF%; P CNS fraction; H OTU; A density; O special-row flag; B/L unused strings |

`G.D()/V.E()` переводят CNS в проценты и округляют до десятых; таблица GF
округляется отдельно. Некоторые getters возвращают строки или пустую строку
для нулевого значения, поэтому адаптер читает private properties непосредственно.

## F — преобразования и округления

Нет состояния кроме неиспользуемого public boolean A. `B(double)` применяет
`Math.rint(x*10)/10` (ties-to-even), `J(double)` — `BigDecimal.valueOf` с
HALF_UP на 2 знака, `A(double,int)` — произвольная точность. Эти правила различны.
`E/F` конвертируют глубину в избыточное/абсолютное давление с фиксированным
морским давлением; `A(double)` — барометрическая модель, G/H — L/CuFt, C/D — bar/psi.

## M — история и поверхностный интервал

I — массив предыдущих J; E/G — N2/He после surface interval; A/F — CNS/OTU;
B/H/C/J — backup этих четырёх значений; D — singleton. `C()` делает backup,
`B()` восстанавливает, `A(J,int)` сохраняет по номеру, `A(int,int)` переносит
ткани через выбранную модель и обновляет CNS/OTU.

CFR ошибочно восстановил цикл увеличения массива `A(J,int)`. Оригинальный
байткод копирует элементы в новый массив; адаптер вызывает оригинал.
`M.A(int,int)` использует **целочисленное** `n/60` при вычислении CNS half-time
1.5 часа и сбрасывает OTU при `n/60 >= 24`; это наблюдаемое соглашение сборки,
не рекомендация для нового планера.
