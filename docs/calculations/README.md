## Индекс численных результатов

| Категория | Входы → выходы | Источники | Статус |
|---|---|---|---|
| Bühlmann B/C | профиль, газы, ткани, GF → потолок, остановки, ткани | A/S, O/J | восстановлено; проверенные случаи в coverage.json |
| VPM-B | профиль, консерватизм → bubble state, потолок, остановки | D/H, O/J | восстановлено; проверенные случаи в coverage.json |
| Высота | высоты, часы → surface pressure, начальные ткани | F, A/S/D/H | найдено |
| Повторные погружения | конечные ткани, interval → начальные ткани, CNS/OTU | M, A/S/D/H | найдено |
| Расход и баллоны | профиль, RMV/OCR, сценарий, баллоны → объёмы/давления | W/R/Y, h/Tank | расход проверен; резервы не найдены |
| Смешивание | начальный/целевой состав и давление, top-up → добавки/стравливание | K/T/i/j/Q/Z/X | найдено |
| MOD/PO2 | газ, PO2 limit, глубина → пределы глубины/давления | K/DP/W/R/Y/F | найдено |
| END | N2/O2/He, глубина → эквивалентная наркотическая глубина | A/S/D/H/K | найдено, часть величин вычисляется без вывода |
| Плотность | состав и pressure → г/л | A/D/K | найдено в CCR/смешивании; OC-таблица не имеет отдельного столбца |
| CNS/OTU | PO2 и время, interval → нагрузка | A/S/D/H/M | найдено |
| Ratios | bottom time, таблица остановок → отношения и группы | W/R/Y | найдено |
| Range tables | базовый план, диапазоны → набор планов | W/R/Y | найдено |
| Графики тканей | snapshots, коэффициенты → N2/He, M-values | W/R/Y/A/S/J | найдено |
| Единицы/округления | значения, unit mode → преобразованные/показанные числа | F/O/G/V | найдено |

Индекс охватывает все обнаруженные категории численных выходов, а не обещает
функции, которых нет в поставке. Стоимость заправки **найдена и проверена** в X.B(). Резервы не найдены;
газовые объёмы в этой поставке прямо обозначены как no reserves. Для
прочих UI-полей сохранён полный снимок `ui-outputs.json`, чтобы при дальнейшем
разборе не потерять отдельные столбцы, параметры и производные результаты.

Каждый содержательный вывод далее должен иметь статус: подтверждено байткодом,
подтверждено выполнением, гипотеза или не восстановлено. Публичная формула модели
не является доказательством того, что именно так работает этот JAR.
