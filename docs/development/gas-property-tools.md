# MOD/END, плотность и подбор смеси (T01–T03)

Три инструмента вызывают GasProperties из чистого Dart-ядра. MOD/минимальная
глубина используют положительные пределы PO₂ с min<max, END — глубину и
наркотичность O₂0/0,3/1/2. Нулевой O₂ явно делает рабочие глубины недоступными.
Плотность — эмпирическая линейная модель г/л, не EOS заправки; рядом показана
эквивалентная глубина воздуха. Подбор показывает все три доли O₂/He/N₂.

Давление берётся из настроек выбранного погружения, включая барометрическое
давление высоты; оно показано над формой. Неприменимая высота не приводит к
аварии формы, расчёт сообщает ошибку. Смена этого контекста делает старый
результат неактуальным. Неверный ввод не заменяет старое число новым успехом.

Каждый инструмент имеет отдельные raw drafts с явной единицей. В метрической
форме PO₂ подписан bar, в имперской — ATA. Смена единиц преобразует значения
без округления до экранной точности. Если хотя бы одна размерная величина
нечисловая или преобразование переполняется, сохраняются прежние подписи и
ввод с пояснением. После исправления преобразование выполняется. Десятичная
запятая принимается. Переходы между инструментами/разделами и восстановление
другого документа сохраняют именно его drafts, без переноса чужого ввода.
Прежний MOD default1,4ATA отображается в метрической форме как1,41855bar.

Кнопка переноса появляется только для результата подбора. Она открывает выбор
существующего уровня и подтверждение. Отмена сохраняет план; подтверждение
заменяет только состав, сохраняя глубину/длительность/режим/setpoint. План,
изменившийся за время диалога, не получает газ молча. Неприменимая CCR-смесь
отклоняется. Изменение самого инструмента не инвалидирует декомпрессию.

Widget tests покрывают normal/invalid/stale, сумму долей, min/max, нулевой O₂,
невозможный подбор, явный перенос/отмену, imperial/altitude, overflow и открытие
другого документа. Три размера375×667/667×375/1440×900 проверены при text200.
Native macOS сценарий проходит неверный состав → подбор → явный перенос,
проверяя фактический состав в запросе. Ядро проверено отдельно численными
эталонами; UI тесты проверяют связку формы и ядра.
