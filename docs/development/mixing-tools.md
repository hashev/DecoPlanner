# Смешивание и стоимость (T04/T08)

T04 использует partialPressureMix и continuousMix, а не fixtures. Доступны
идеальная/van der Waals EOS с явной температурой K; порядок O₂/He и состав
дозаправки — только для парциальных давлений. Continuous предоставляет один/
два потока; два пути доступны для двух потоков. Пределы O₂/He относятся к
каждому feed, чистое предварительное добавление показывается отдельным шагом.

Bounded расчёт выполняется в отдельном isolate:100000iterations/3seconds.
MixingViewModel связывает ответ с revision запроса. Изменение входа/метода
инвалидирует рецепт, скрывает инструкцию и стоимость; поздний ответ на старый
ввод не восстанавливает успех. Завершение после dispose игнорируется. Неудача
сохраняет исходные поля и старый snapshot с неактуальным статусом; impossible
отдельно предлагает изменить доступные газы/пределы. Стравливание показывает
сколько убрать и до какого остаточного давления, затем каждый реальный шаг.

Draft хранит method/EOS/order/variant/path и значения с bar/PSI tag. Изменение
единиц преобразует давления без округления; неверный ввод сохраняет прежние
подписи. Неактивные поля остаются в draft и не участвуют в запросе. Ввод и
инструменты не изменяют dive revision. Открытие другого документа заменяет draft.

T08 получает тот же recipeRevision и purchased source amounts. Для continuous
воздух учитывается как источник дозаправки, а не выдуманная сумма feed-газов.
Водяной объём вводится в явно подписанных L или копируется из справочника.
Цены явно за свободный L, фиксированная плата дозаправки взимается один раз,
если этот компонент добавлен. Нулевая цена допустима. Общая денежная единица
задаётся пользователем, конверсия валют отсутствует. Free volume basis294K/1ATA
указан в форме; output L/CuFt зависит от настройки вида, подписи цен всегда L.
Проверяется сумма компонентов; новая версия рецепта делает стоимость stale.

Проверки: реальный isolate, ideal/real, partial/continuous, order/path, budgets,
late response, drain/impossible/recovery, imperial equivalence, recipeRevision,
аналитическая стоимость O₂, zero/negative prices, каталог баллонов, три размера
при text200. Полные независимые численные matrices mixing проверяются в ядре.
Native macOS integration проходит recipe→cost→edit→stale с фактической суммой.
