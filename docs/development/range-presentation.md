# Диапазоны P08

Диапазон меняет глубину и длительность последнего введённого уровня копии
запроса. Исходный план сохраняется. Доступны базовый вариант, исключение
дополнительных OC-газов и исключение переключений; CCR-дилюент сохраняется.
Оси включают обе границы при кратном шаге, число ячеек ограничено 1000.
Перед запуском более 100 ячеек требуется явное подтверждение.

RangeWorker запускает чистое ядро в отдельном isolate. Общий бюджет —
5 миллионов итераций / 60 секунд, внешний timeout — 65 секунд. Отмена убивает
isolate. Каждая компактная ячейка подтверждается принимающей стороной перед
следующей; полные трассы тканей не накапливаются во всей матрице.
Проверяются identity, revision, dependency/model/protocol version, порядок
ячеек и конечность метрик. Ошибка отдельного сценария остаётся в таблице;
общая отмена или исчерпание бюджета завершает задачу с явным статусом.

Матрица и список показывают runtime, подъём, декомпрессию и первую остановку.
Открытие успешной ячейки повторно рассчитывает её точный сохранённый запрос
и даёт полный профиль, ткани и расход. Изменение исходных физических входов
или восстановление другого документа делает диапазон устаревшим; смена единиц
и темы сохраняет результаты. Устаревшие данные не используются для расчёта
баллонов. Черновики и их единицы хранятся отдельно для dive/bailout.

Проверки: 9 worker tests и 7 widget tests (реальные OC/CCR/bailout расчёты,
частичная ошибка, протокол, timeout, hard cancel, восстановление, единицы,
смена документа с той же revision, 200% текста на трёх размерах).
Native macOS integration проходит путь план → диапазон → полный результат.
Сравнение range с одиночным вызовом ядра проверяет orchestration;
это не дополнительный независимый численный эталон.
