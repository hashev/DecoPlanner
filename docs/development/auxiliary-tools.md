# Дозаправка, уравнивание и ёмкость (T05–T07)

Все три экрана вызывают чистое ядро, имеют отдельные drafts, явный расчёт и
статус устаревшего результата после редактирования. Ошибки не стирают ввод.
Навигация Back и последующее открытие восстанавливают поля; чужой документ
заменяет draft. Сам расчёт не меняет входы плана.

T05 — идеальное смешение исходного и добавляемого газа по давлениям. Итоговое
давление строго выше исходного (контракт формы T05). Core API отдельно
поддерживает identity при равных давлениях; форма не считает его дозаправкой.
Сумма долей проверяется возле обоих полей. Результат показывает O₂/He/N₂.

T06 — идеальное уравнивание при общей температуре, без EOS/теплового перехода.
В metric вводится водяной объём L; в imperial именно tank factor, свободные
CuFt/100PSI при1ATA. Перевод factor = L×100×barPerPsi/(barPerAta×litresPerCuFt).
Единый множитель сокращается в весах объёмов; это не номинальные CuFt баллона.
Давления bar/PSI преобразуются, физический результат остаётся прежним.
Нулевые давления допустимы, нулевые объёмы — нет.

T07 имеет явное направление L/bar→CuFt/PSI либо обратно. Поля постоянно имеют
свои подписи, глобальная смена единиц их не переименовывает. Используется
CylinderCapacity с поправкой1+0,0002615×bar. Это приближённая номинальная ёмкость,
не идеальные свободные литры и не гарантия спецификации изготовителя. Derived
значения проверяются на конечность до публикации результата; overflow сохраняет
предыдущий результат с неактуальным статусом.

Проверки:13widget cases — normal/pressure equality/lower pressure, сумма долей,
нулевой объём, imperial factor/pressure, оба направления capacity, overflow,
navigation/back/drafts и375×667/667×375/1440×900 при text200 для каждого экрана.
Физические формулы проверены аналитически и независимыми fixtures в ядре.
