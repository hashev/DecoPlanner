# PDF-отчёты и предпросмотр

`PlannerReport` замораживает условия и строки представления, не меняя план.
Из основного результата, bailout или ячейки диапазона доступен печатный вид;
диапазон экспортируется также целиком, включая ошибки и статус частичной отмены.
Указаны модель/версия, GF либо VPM-консерватизм, единицы, скорости/сетка,
давление/высота/SI, газы и переключения, сегменты и raw численные результаты.
Для одиночного результата приведены начальные 16 тканей. Неизвестный CNS
остаётся недоступным с причиной, OTU и декомпрессия сохраняются.

`PlannerPdf` загружает Fira Sans из bundle и создаёт документ в отдельном isolate.
HTTP и Google Fonts API не используются. Формат A4, таблицы продолжаются
с заголовками, страницы нумеруются. `PdfPreview` выполняет нативный raster.
Редактирование исходных условий скрывает устаревший preview и блокирует экспорт.
Тема и единицы не меняют физические расчёты; в PDF сохраняются единицы снимка.

`NativePdfActions` использует printing для системной печати/отправки;
возможности запрашиваются через Printing.info. Неподдерживаемые действия
недоступны и имеют пояснение. На desktop сохранение использует native Save
через file_selector; на iOS/Android — системную отправку с возможностью сохранения
в файлы. Это передача системному диалогу, не подтверждение конечной доставки.
На iPad передаётся прямоугольник origin. Печать на macOS имеет sandbox entitlement.
Отмена/ошибка сохраняет байты и preview для повтора.

Версии для Flutter3.41.6/Dart3.11.4: pdf3.12.0, printing5.14.3.
image4.8.0 зафиксирован точным constraint: image4.11.0 вызывает decodeLazy,
которого нет в SDK-совместимом archive4.0.9. Это реальная compiler failure,
устранённая без обновления SDK и остальных зависимостей.

## Проверено

- Содержание metric/imperial и CNS unavailable, все физические строки.
- Диапазон на 1000 строк: pagination, отдельные ошибки, отсутствие подмены нулём.
- Тесты generation failure/retry, cancel/failure действий, stale blocking.
- Три размера (375×667,667×375,1440×900), текст200%, прокрутка действий.
- macOS: сборка с plugin, Printing.info, настоящий raster с кириллицей;
  native flow диапазон → полная ячейка → PdfPreview.
- Poppler text extraction и визуальная проверка страниц, русских шрифтов,
  таблиц/повторяемых заголовков и footer. QA PDFs — в игнорируемом local/validation/pdf.

## Нативные диалоги macOS

Отдельный интерактивный integration test
`integration_test/manual/pdf_dialogs_test.dart` выполнен через официальный MCP
с `--run-skipped`. Он по умолчанию opt-in: нужен оператор и desktop accessibility
client; unattended suite не должен открывать OS-диалоги. На macOS проверены:

- Успешный native Save в QA-папку; 21370байт и SHA256 совпали с исходными
  PDF-байтами побайтно (10e59996db4c985ce53e52bc48ddba7c22346a1d387462e8fae349e4a8a048ce).
- Отмена следующего Save и системного Print; adapters вернули cancelled.
- Настоящий Share picker с PDF-документом, закрытый без передачи получателю.
  macOS API возвращает handoff сразу; это не обещание конечной доставки.
- После действий preview, план revision0 и кнопка повтора остаются доступны.

Проверка обнаружила реальное зависание: dynamic layout printing5.14.3 на macOS
в knowsPageRange блокирует main thread через semaphore.wait, ожидая onLayout
от Dart. При merged UI/platform threads callback не выполняется. Для готового
A4-снимка установлен dynamicLayout:false; PDF поступает до открытия print panel.
После исправления полный интерактивный тест прошёл. Unit test pdf_actions_test
проверяет параметр dynamic=false и mapping native cancellation.

Первый успешный по действиям запуск ещё выявил особенность test harness:
подключение AX создаёт engine-owned semantics handle во время теста и меняет
baseline leak-check. Harness ждёт AX в setUpAll до baseline; проверка утечек
не отключена. Итоговый native test проходит целиком, а ранние прерванные/упавшие
запуски не считаются PASS.

Физическая печать не выполнялась: выбранный системный принтер offline.
iOS/Android/Windows не заявлены как exercised: доступных устройств/Windows-host
здесь нет. Их возможности фиксируются отдельной платформенной матрицей11.2.
