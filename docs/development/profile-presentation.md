# Профиль и ткани (P05)

ProfileData содержит начальное физическое состояние и конец каждого настоящего
сегмента. График не добавляет фиктивное насыщение на поверхности и не вычисляет
промежуточные ткани интерполяцией. Выбор ближайшей точки касанием, ползунок и
кнопки перехода используют один индекс; ползунок доступен Tab и стрелками.
Численная таблица открывает те же точки и позволяет выбрать их.

Время идёт вправо, глубина вниз; метры/футы меняют только представление.
Ascent-only сохраняет начало/конец ascent/decompression и разрывает линию через
скрытые hold/travel участки. Он не соединяет раздельные подъёмы выдуманной линией.
Наложенный снимок отличается штрихами и подписью имени/даты/версии модели.

График тканей показывает реальные парциальные давления N₂/He всех16компартментов
в выбранной точке. Численные карточки фильтруются списком или касанием графика.
M-value для B/C — mixed a + ambient/b при GF100%; фактический GF — отношение
перенасыщения к этому диапазону, может быть отрицательным. Это не настройка GF.
Для VPM-B M-values/GF неприменимы. Давления используют pressure context результата.
Ratios/groups получены из того же schedule, без второго расчёта декомпрессии.

Сохранение сравнения создаёт именованный immutable snapshot входов и результата,
не меняет revision. Снимки сохраняются внутри versioned JSON, переживают
save/new/open; удаление подтверждается. Новые входы оставляют открытый старый
снимок с явным статусом и блокируют сохранение его как актуального.

Проверки: соответствие endpoint states, ручная формула M-value, VPM applicability,
разрывы multilevel ascent, touch и клавиатура, stale protection, save/reopen,
отмена/подтверждение clear. Widget layouts375×667/667×375/1440×900 text200 проходят.
Реальный macOS OC flow открывает P05, выбирает следующую точку и возвращается.
VoiceOver/TalkBack/Narrator ещё требуют отдельной проверки10.3.

При проверке сохранения найдена гонка: завершение уже начатой записи могло
заменить изменённые в ожидании metadata. DocumentSession сохраняет новые metadata
в памяти, а следующая queued save публикует их; проверено блокировкой стадии
beforePrimaryPublish и последующей проверкой содержимого файла.

Масштаб временной оси ×1–×4, scrollbar и кнопки горизонтального перемещения
поддерживают touch/keyboard; сброс «Весь профиль». Тема/единицы сохраняют
масштаб и расчёт. Подробности: [состояния и доступность](runtime-accessibility.md).
