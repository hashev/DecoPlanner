# Расчётные настройки и справочники

S01 редактирует копию CalculationSettings. Текущая модель снаружи редактора
показывается текстом; её выбор, GF/VPM и остальные параметры применяются
только кнопкой. Отмена не изменяет запрос. Для B/C доступны GF Low/High,
для VPM — консерватизм0–4 и critical volume; неприменимые поля скрыты.
Параметры VPM, не представленные в исходном UI, сохраняются без изменений.

Скорости, физическая сетка/последняя остановка, minimum stop, учёт спуска,
низкий CCR setpoint, RMV/OCR и высота передаются в ядро. Высота выключена —
поля сохранены и не участвуют; акклиматизация отключает параметры поездки.
Время подъезда/ожидания — явно минуты. Depth/rate и flow подписаны в текущих
единицах; неизменённые значения сохраняют точные исходные канонические числа.
Нельзя переключить единицы за открытым модальным редактором.

«Сохранить по умолчанию» сохраняет reserved SettingsPreset default-settings
в текущем документе; текущие входы/revision/result не меняются. Новый документ
получает этот preset и справочники копиями. Новое погружение в существующем
плане продолжает наследовать настройки выбранного погружения. Открытие иного
документа использует его собственные defaults. Число стопов в ratios — отдельная
настройка представления; её изменение не инвалидирует декомпрессию.

P03 содержит отдельный список switches, редактируемый копией. Состав O₂/He,
глубина, setpoint CCR, minimum stop и lost передаются без округления в GasSwitch.
OC-план не предлагает загрузить набор с CCR switches. В CCR поясняется отличие
обычного OC-переключения от отдельной ветви bailout. Внешняя кнопка «Применить
переключения» меняет запрос, а «Сохранить как набор» — только справочник.

S02 позволяет создать/редактировать/именовать/удалить наборы и баллоны с отменой
и подтверждением удаления. Применённые элементы — физические копии, а не
ссылки по ID; зависимостей, требующих замены при удалении каталога, не создаётся.
Подтверждение прямо сообщает сохранение копий в плане. P06 выбирает водяной
объём/рабочее давление из каталога с сохранением выбранного количества баллонов.
Номинальная CuFt-конверсия доступна в imperial редакторе каталога и T07.

Schema1 расширена необязательными gasSets и SettingsPreset.ratioStops;
при чтении прежних документов значения по умолчанию [] и5. Хеш проверяется
по исходному payload до нормализации. Все поля switches, включая CCR и lost,
сохраняются; duplicate IDs отвергаются. Более новые версии схемы по-прежнему
не принимаются. Баллоны и настройки существовавших документов сохраняются.

Проверки: unit round-trip/missing field/duplicate ID; session save/open/create
с defaults и каталогами; widget apply/cancel, неверный GF/состав, OC/CCR/lost,
имперская точность, высотный travel с реальным B расчётом, сохранение каталога
отдельно от плана, отмена/подтверждение удаления, выбор баллона в PSI без
переинтерпретации L/bar. Форма S01 проверена375×667/667×375/1440×900 при text200.
S02 управляет ascent-only, автоматическим сохранением предыдущего профиля при
успешном пересчёте (обратный смысл legacy Clear previous) и сохранением графика
при сбросе. Параметры сохраняются сразу, именованные снимки от автонастройки
не зависят. Session помнит точные входы успешного результата; после изменения
можно открыть его график со старыми настройками и статусом stale. Неизвестные
исторические входы восстановленного cache не выдумываются. Reset с сохранением
создаёт frozen comparison; отключение очищает снимки/retained graph, численный
stale cache остаётся для прозрачного статуса результата. Повторный пересчёт
после reset не дублирует comparison ID.

Каталог баллонов в imperial редактирует nominal CuFt/PSI через CylinderCapacity,
а в metric — L/bar. Неизменённый imperial ввод сохраняет точные L/bar. Это
приближённая номинальная ёмкость; T06 tank factor имеет другой смысл. P06
по-прежнему редактирует реальные L/количество и давление расхода.

[settings-feature-coverage.json](settings-feature-coverage.json) сопоставляет80
действий/полей/колонок P03/S01/S02 с реализацией и тестами; структурные контейнеры
не считаются дополнительными функциями. `python3 tool/audit_settings_features.py`
проверяет полноту, исходный hash и наличие evidence. Это source/behavior audit,
не утверждение о native-проверке каждого legacy control. P03 clear меняет только
копию списка до Apply, Cancel сохраняет исходные переключения. P05 clear очищает
наложения с подтверждением, не удаляет численный результат основного графика.
