## Purpose

Защитить основную ветку публичного репозитория от прямых изменений, сохранив возможность самостоятельного merge владельцем после автоматической проверки.

## ADDED Requirements

### Requirement: Изменения main через PR
Main MUST принимать изменения только через PR с успешным обязательным CI, без требования approving review. Политика MUST распространяться на владельца без настроенных bypass; force push и удаление main MUST быть запрещены.

#### Scenario: Прямая запись
- **WHEN** владелец или приглашенный участник пытается выполнить прямой push в main
- **THEN** GitHub отклоняет изменение

#### Scenario: Самостоятельный merge
- **WHEN** PR актуален относительно main и все обязательные проверки успешны
- **THEN** владелец может выполнить merge без одобрения второго человека

#### Scenario: Неуспешная проверка
- **WHEN** обязательный CI отсутствует или неуспешен
- **THEN** merge запрещен

### Requirement: Участие по приглашению
Защита main MUST сохранять публичную доступность репозитория и существующую политику создания PR только collaborators.

#### Scenario: Проверка настроек
- **WHEN** настройка защиты завершена
- **THEN** API подтверждает публичность, collaborators_only и активное правило main с обязательным CI
