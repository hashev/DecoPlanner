## Purpose

Предоставить пользователю проверенные устанавливаемые сборки Windows, macOS и Android через GitHub Releases с устойчивой идентичностью приложения.

## ADDED Requirements

### Requirement: Выпуск по стабильному тегу
Публикация MUST запускаться только push тега vMAJOR.MINOR.PATCH, указывающего на коммит из main. Все проверки и сборки MUST относиться к этому коммиту. Неверный тег, неподдерживаемая версия или ошибка проверки MUST блокировать публикацию.

#### Scenario: Допустимый тег
- **WHEN** опубликован корректный тег на коммите из main и все проверки успешны
- **THEN** создается GitHub Release с этой версией и исходным SHA

#### Scenario: Обычное изменение ветки
- **WHEN** выполняется push main или проверяется PR
- **THEN** публичный релиз не создается

#### Scenario: Недопустимый источник
- **WHEN** тег имеет неверный формат или его коммит не принадлежит main
- **THEN** релиз не публикуется и выводится причина

### Requirement: Полный комплект сборок
Релиз MUST содержать Windows x64 ZIP со всем runtime, macOS ZIP с приложением и заявленными архитектурами, универсальный Android APK, контрольные суммы SHA-256 и инструкции установки с ограничениями подписи. Публичный релиз MUST появляться только после готовности всего комплекта.

#### Scenario: Неудачная сборка
- **WHEN** отсутствует или не проверен хотя бы один обязательный артефакт
- **THEN** публичный релиз не появляется

#### Scenario: Повторный запуск
- **WHEN** повторяется выпуск существующего тега
- **THEN** процесс не заменяет молча опубликованные файлы или связь версии с исходным SHA

### Requirement: Постоянная подпись Android
Публичный APK MUST иметь постоянный идентификатор и отдельную постоянную release-подпись DecoPlanner. Ключ MUST храниться вне Git с резервной копией; CI MUST проверять ожидаемый сертификат. Отсутствие ключа MUST блокировать выпуск без fallback на debug-подпись.

#### Scenario: Установка и обновление APK
- **WHEN** пользователь скачал APK из GitHub Releases, разрешил установку из этого источника и устанавливает следующую версию
- **THEN** приложение устанавливается и обновляется поверх предыдущей release-версии с сохранением пользовательских данных и увеличенным versionCode

#### Scenario: Ключ отсутствует или неверен
- **WHEN** release-секреты отсутствуют или сертификат не совпадает с ожидаемым
- **THEN** публикация прерывается, секреты не попадают в логи и артефакты
