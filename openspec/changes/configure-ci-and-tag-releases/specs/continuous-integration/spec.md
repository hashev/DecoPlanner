## Purpose

Обеспечить воспроизводимую автоматическую проверку изменений планировщика без приватных исследовательских файлов и секретов выпуска.

## ADDED Requirements

### Requirement: Обязательная проверка изменений
Каждый PR в main и каждый push в main MUST запускать форматирование, статический анализ, тесты приложения и ядра, публичные аудиты и проверку спецификаций на фиксированном SDK. Один стабильный итоговый статус MUST отражать результат всех обязательных проверок.

#### Scenario: Ошибка обязательной проверки
- **WHEN** хотя бы одна обязательная проверка завершилась ошибкой, отменена или неожиданно пропущена
- **THEN** итоговый статус неуспешен и не разрешает merge

#### Scenario: Чистый checkout
- **WHEN** CI выполняется без local/ и секретов выпуска
- **THEN** проверки используют опубликованные эталоны и зависимости репозитория без запуска исходного Java-приложения и пересоздания эталонов

### Requirement: Проверка целевых платформ
CI MUST проверять сборку Windows, macOS и Android на подходящих runner и автоматический нативный сценарий macOS. Интерактивные тесты системных диалогов MUST оставаться ручными и не задерживать CI.

#### Scenario: Платформенная ошибка
- **WHEN** сборка одной платформы или автоматический нативный сценарий macOS не проходит
- **THEN** обязательный итоговый статус неуспешен, даже если остальные платформы прошли

### Requirement: Изоляция секретов
PR-проверки MUST работать без release-ключей и разрешения публикации. Недоверенный код PR MUST NOT исполняться в контексте привилегированного workflow.

#### Scenario: Проверка PR
- **WHEN** выполняется PR CI
- **THEN** ключ Android и токен с правами публикации недоступны заданиям
