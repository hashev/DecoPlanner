## MODIFIED Requirements

### Requirement: Границы подготовки GitHub
Первоначальная подготовка MUST оставить понятный локальный Git-репозиторий и проверенный состав файлов без автоматического создания remote, commit, push, CI/CD и публикации сборок. Последующее явно разрешенное изменение MUST иметь возможность настроить CI/CD и публикацию. Лицензии третьих сторон MUST быть сохранены; собственная открытая лицензия MUST NOT выбираться без решения владельца.

#### Scenario: Завершение подготовки
- **WHEN** приложение и репозиторий подготовлены
- **THEN** доступен отчёт о составе и проверках, а удалённый репозиторий, workflows и опубликованные релизы не создаются

#### Scenario: Отдельная задача CI/CD
- **WHEN** владелец отдельно поручает настройку CI/CD после публикации репозитория
- **THEN** workflows, защита ветки и выпуск сборок выполняются в рамках нового изменения с сохранением MIT и сторонних лицензий
