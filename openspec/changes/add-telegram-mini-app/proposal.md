# Proposal

## Why

Пользователи смогут открыть DecoPlanner по ссылке в Telegram без установки отдельного клиента. Расчёты и документы остаются на устройстве, поэтому для первой версии достаточно статической публикации на GitHub Pages.

## What Changes

- Добавить Flutter Web как цель сборки для Telegram Main Mini App.
- Переиспользовать редактор, расчётное ядро и газовые инструменты. Адаптировать фоновые расчёты, локальные документы и файловые действия к WebView.
- Поддержать перенос планов через совместимый JSON и просмотр и сохранение PDF.
- Добавить проверку веб-сборки в CI и публикацию на GitHub Pages. Первая версия рассчитана на локальное хранение без регистрации и синхронизации.

## Capabilities

### New Capabilities

- `telegram-mini-app` — запуск и работа веб-клиента DecoPlanner в Telegram, локальное хранение и статическая доставка.

### Modified Capabilities

## Impact

Flutter-приложение, платформенные реализации фоновых задач и документов, браузерная проверка `deco_core`, GitHub Actions, GitHub Pages и конфигурация Main Mini App в BotFather. Действующие требования к автономному запуску нативных приложений сохраняются.
